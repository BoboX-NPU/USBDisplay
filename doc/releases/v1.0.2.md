# USB Display 1.0.2

A clearer, more polished drag-to-install disk image. Application capture and window behavior are unchanged.

- [DMG — Apple Silicon and Intel](https://github.com/BoboX-NPU/USBDisplay/releases/download/v1.0.2/USBDisplay-1.0.2-macOS-universal.dmg)

Version 1.0.2 (build 6), macOS 14+, universal `arm64` and `x86_64`.

## Changes

- A white and blue-gray Retina installation background matching the app icon.
- Aligned native app and Applications icons, a clear arrow, and Chinese/English installation guidance.
- Saved icon-view window layout, with only the two installation targets visible. The layout accommodates Finder's own tab/path/status preferences.
- Reproducible artwork/layout tooling with temporary dependencies and cleanup of incomplete packages.

The packaged app retains Developer ID signing, Apple notarization, and a stapled ticket. Normal first-launch confirmation and Camera permission prompts remain expected. The DMG is a transport container; separate notarization of the container is not claimed.

## Validation and limits

The installer is visually checked in Finder, and its packaged app is checked for strict signature integrity, ticket validity, and Gatekeeper acceptance. Application startup/black-preview investigations, broader hardware/OS coverage, and intermittent full-screen test behavior remain separate follow-ups. See the [current state](https://github.com/BoboX-NPU/USBDisplay/blob/v1.0.2/doc/current.md) and [design notes](https://github.com/BoboX-NPU/USBDisplay/blob/v1.0.2/doc/design/dmg-installer.md) for detailed evidence and limits.

Older releases and download files remain available without replacement.
