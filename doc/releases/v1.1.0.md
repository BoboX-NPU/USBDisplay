# USB Display 1.1.0

Released 2026-11-14. Version 1.1.0, build 8.

## New Features

- Automatically check for updates and download ordinary updates inside the app with a native progress indicator.
- Wait for the user to choose `Install and Relaunch` before restarting to install the update. Normal quit cancels an unconfirmed prepared update.
- Add `Check for Updates…` and `Automatically Check for Updates` to the application menu.
- Verify signed update feeds and update archives. Subsequent updates download directly from GitHub without opening a browser.

## Installation and Upgrade

Requires macOS 14 or later. The same download includes Apple Silicon and Intel architectures.

Version 1.0.3 and earlier do not contain an updater. Install 1.1.0 manually once by dragging `USB Display.app` into Applications. Subsequent releases can be downloaded and installed from the app. Automatic checks can be disabled in the application menu.

The app and Sparkle helpers are Developer ID signed, and the app is notarized by Apple with a stapled ticket. Apps extracted from both the DMG and ZIP pass signature, ticket, and Gatekeeper checks. Normal first-launch download confirmation and Camera permission prompts can remain. No separate notarization of the DMG container is claimed.

## Maintenance

- Ship Sparkle's complete license in a separate bundled resource, preserving reproducible device-data notices.
- Include a signed `appcast.xml` with the release assets. Update signing is independent of Apple code signing.

## Known Limits

Existing physical-device, older-macOS/Intel, prolonged-capture, and intermittent full-screen fixture follow-ups remain unchanged. The latest full application test run passed 109/111, with the same two previously recorded full-screen test failures; all six updater tests passed. See [current validation](https://github.com/BoboX-NPU/USBDisplay/blob/main/doc/current.md).
