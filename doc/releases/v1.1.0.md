# USB Display 1.1.0 — Release Preparation

Source version: 1.1.0, build 8. This release is not published yet. The new executable and Sparkle helpers still require Developer ID export and Apple notarization; the existing 1.0.3 ticket does not cover them.

## New Features

- Automatically check for updates and download ordinary updates inside the app with a native progress indicator.
- Wait for the user to choose `Install and Relaunch` before restarting to install the update. Normal quit cancels an unconfirmed prepared update.
- Add `Check for Updates…` and `Automatically Check for Updates` to the application menu.
- Verify signed update feeds and update archives. Release packages remain hosted on GitHub without requiring users to visit the download page for subsequent updates.

## Installation and Upgrade

Requires macOS 14 or later. The release build includes Apple Silicon and Intel architectures.

Version 1.0.3 and earlier do not contain an updater. Install the first updater-enabled release manually by dragging `USB Display.app` into Applications. Subsequent updates can be downloaded and installed from the app. Automatic checks can be disabled in the application menu.

## Release Gates

- Complete Developer ID export, Apple notarization, stapling, and quarantined-distribution checks for this exact app, including Sparkle's embedded helpers.
- Package the notarized export and generate a signed `appcast.xml` using [the update guide](../updates.md).
- Upload the exact DMG, ZIP, checksums, and appcast to the release draft before publication. Verify public downloads and the stable feed afterward.

## Known Limits

- Native update acceptance used isolated, ad-hoc test builds and a signed localhost feed. It does not establish Apple trust or public GitHub delivery for this release.
- Existing physical-device, older-macOS/Intel, prolonged-capture, and intermittent full-screen fixture follow-ups remain unchanged. See [current validation](../current.md).
