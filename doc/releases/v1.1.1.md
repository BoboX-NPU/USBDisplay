# USB Display 1.1.1

Version 1.1.1, build 9.

## Bug Fixes

- Fix a crash when macOS checks whether the sidebar toggle is available. The sidebar divider retains native resizing.

## Installation and Upgrade

USB Display 1.1.0 users can choose **USB Display > Check for Updates…**. After the download finishes, choose **Install and Relaunch**. Scheduled checks are enabled by default.

For a manual installation, open the DMG or extract the ZIP and move **USB Display.app** to Applications. The universal app supports Apple Silicon and Intel and requires macOS 14 or later. The app and embedded Sparkle helpers are Developer ID signed. The app is notarized by Apple and includes a stapled ticket.

## Validation and Known Limits

The release checks cover menu action validation, divider resizing, width persistence, and preview geometry. The complete validation record is available in [current project state](https://github.com/BoboX-NPU/USBDisplay/blob/main/doc/current.md). Live pointer dragging and broader older-macOS and Intel runtime coverage remain open.
