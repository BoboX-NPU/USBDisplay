## Changes

- The app is signed as **Developer ID Application: mingbo xue (9PSN33WBG7)** and notarized by Apple. Both packages contain the app with its stapled ticket for offline verification.
- The app passes strict signature verification, ticket validation, Gatekeeper assessment, and Apple's distribution check with a quarantine marker. Gatekeeper reports **accepted / Notarized Developer ID**.
- The README now contains matching Simplified Chinese and English sections, with direct language navigation. Packaged installation notes are also bilingual.
- The release workflow can package a verified notarized app without rebuilding or invalidating its signature/ticket.

Normal first-launch Internet-download confirmation and Camera permission prompts may still appear. The notarization applies to the embedded app; no separate notarization ticket is claimed for the DMG container.

## Known limits

The previously documented startup/black-preview investigation, physical-device matrix, older macOS/Intel runtime coverage, and continuous interaction/performance verification remain outstanding. This release fixes distribution trust; it does not claim to resolve those runtime issues. See the [installation guide](https://github.com/BoboX-NPU/USBDisplay/blob/v1.0.1/doc/installation.md) and [roadmap](https://github.com/BoboX-NPU/USBDisplay/blob/v1.0.1/doc/roadmap.md).

The final full regression passed all 105 tests, and all nine catalog tests passed. Two full-screen integration tests failed in the initial full run, then passed in the isolated 11-test suite and full rerun without source changes. Their intermittent behavior remains tracked in the window-validation task.

The original 1.0.0 tag and downloads remain unchanged. Users of that ad-hoc-signed release should quit the old app and replace it with this version.
