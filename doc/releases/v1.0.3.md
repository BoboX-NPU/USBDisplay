# USB Display 1.0.3

The approved minimal installer: a pure-white background, one flat curved arrow from USB Display to Applications, and the footer **Connect your iPhone or iPad via USB.**

Version 1.0.3 (build 7), macOS 14+, universal `arm64` and `x86_64`.

Both README language sections point to these downloads. The installer background uses English for every system language; Finder's native controls and filenames remain system-owned.

The app is Developer ID signed, notarized by Apple, and includes a stapled ticket. Normal first-launch confirmation and Camera permission prompts can remain. The DMG is a transport container, without a separately claimed notarization ticket.

Application capture/window behavior is unchanged. The existing startup/black-preview, compatibility, performance, and intermittent full-screen test follow-ups remain documented in the [current state](https://github.com/BoboX-NPU/USBDisplay/blob/v1.0.3/doc/current.md). Older tags and download files remain unchanged.
